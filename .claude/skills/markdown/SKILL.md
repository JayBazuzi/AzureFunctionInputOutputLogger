name: markdown
description: Use when writing or reviewing Markdown such as the README or docs.
---

## Headings

Use ATX headings (`#`, `##`) with a single H1 per file. Don't skip heading levels.

## Code

Use Markdown Snippets. Don't edit the snippet contents directly; instead, edit the source files they reference.

## Lists

Use exactly `1.` for numbered lists for every item, even if the numbers are not sequential.

## Line breaks

Put one sentence per line in a paragraph.
